# SplashDown Waterpark: concept site

A temporary demo of a redesign concept for SplashDown Waterpark (Manassas, VA), made by DevCom Studio
to show the park's owner. Not the official site and not affiliated with the park; photos and logo
belong to SplashDown Waterpark / Prince William County. This repository will be deleted after the review.

Open `index.html` through any static server, or see the GitHub Pages link in the repo description.
